## 🌟 ویژگی‌های برجسته (Features)

- 🟢 **طراحی نئونی مدرن (Spotify Dark Theme):** پالت رنگی مشکی مات `#121212` با اکسنت نئونی `#1ed760` و المان‌های شیشه‌ای بلور (Backdrop Blur).
- ⚡ **اینترو و لودینگ بار ۲ ثانیه‌ای:** اسپلش اسکرین سبک مینیمال دیجیتال با لودینگ درصدی فوق‌سریع و ورود نرم به پلیر.
- 📱 **سازگاری کامل با تلگرام مینی‌اپ (Telegram WebApp SDK):** پشتیبانی از حالت تمام‌صفحه (Full-Screen Expand)، کلید منوی اختصاصی و پاسخگویی لمسی.
- 🎬 **دسته‌بندی‌های کپسولی متنوع (Category Pills):**
  - 🇮🇷 **شبکه‌های سراسری و استانی ایران** (همه کیفیت‌ها)
  - ⚽ **ورزش و فوتبال زنده جهان**
  - 🍿 **سینما و فیلم‌های ۲۴ ساعته**
  - 🎵 **موزیک ویدیو و کنسرت‌های بین‌المللی**
  - 🧸 **کارتون، انیمیشن و سرگرمی کودک**
  - 🌍 **شبکه‌های انگلیسی، آمریکا و ترکیه**
  - 🔞 **بخش محافظت‌شده بزرگسالان (+18)** مجهز به سیستم احراز هویت و قفل امنیتی رمز عبور.
- 🛡️ **پلیر بهینه‌شده HLS.js:** بازیابی خودکار و هوشمند پکت‌های زنده بدون فریز، حذف کنترل‌های دست‌وپاگیر و درج نشانگر تپنده 🔴 زنده (Live Pulse).

## 🛠️ راه‌اندازی لوکال (Self-Hosting)

```bash
# دریافت سورس کد
git clone https://github.com/arianradshan1-cloud/dumble-player.git

# ورود به پوشه
cd dumble-player

# اجرای سرور تست با پایتون
python3 -m http.server 8080
```
سپس آدرس `http://localhost:8080` را در مرورگر باز کنید.
